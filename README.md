# Maroush website

Static site for maroush.com, built by The Wonder Agency and served with GitHub Pages.

## Pages
Home, Restaurants, one page per restaurant (Crockers Folly, Beauchamp Place, Earls Court, Edgware Road, Kings Road, High Street Kensington), Menu, Our story, Events & catering, Contact.

## Editing
Every page shares one header, footer, stylesheet (`assets/site.css`) and script (`assets/site.js`).
The pages are generated by `src/build.py`, which holds the restaurant details (address, phone, hours) and the menu in one place.

## Before launch
- Forms: set `data-endpoint` on the catering and contact forms (for example a Google Apps Script web app).
- Menu PDFs still link to the old WordPress site; copy them into `assets/` and update the links.

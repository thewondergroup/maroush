# Maroush website: classic version

The same pages and content as the new design in the repo root, restyled in the traditional maroush.com look
(Cinzel and Lato, white, slate and gold, with film and photo headers).

- New design: `/` (repo root)
- Classic version: `/classic/`

Both are generated from `src/build.py`. After rebuilding the root pages, run `python3 src/make_classic.py`
to refresh this folder. The classic look lives in one file: `assets/classic.css`.
